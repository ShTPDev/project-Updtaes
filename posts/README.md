# Posts Directory

This folder contains all blog posts/updates as individual JSON files.

## Structure
- Each post is stored as `posts/<post-id>.json`
- `index.json` contains an array of all posts (generated by `scripts/generate-posts-index.js`)

## Post Format
```json
{
  "id": "unique-id",
  "title": "Post Title",
  "body": "Post content...",
  "createdAt": "2025-11-14T12:00:00.000Z",
  "displayDate": "2025-11-14",
  "displayTime": "12:00",
  "imageUrls": []
}
```

## Workflow
1. Create posts via the Admin page
2. Download the generated JSON file
3. Save it to this `posts/` folder
4. Run `node scripts/generate-posts-index.js` to update `index.json`
5. Commit and push to GitHub

The site will automatically load posts from `posts/index.json`.
